# DNA Mutation and Transcription Simulator

## Overview
This project is a Python-based simulation of DNA mutations and transcription processes. It models how changes in DNA sequences can occur and how DNA is transcribed into RNA.

## What I learned
Through this project, I developed:
- A deeper understanding of how mutations affect genetic sequences
- Insight into transcription as a key step in gene expression
- Programming skills in Python, including string manipulation and logic design

## Relevance to Pharmaceutical Science
Understanding DNA mutations is essential in modern pharmaceutical research, particularly in:
- Drug development targeting genetic mutations
- Personalised medicine
- Identifying disease-causing genetic variations

This project reflects my interest in applying computational approaches to biological problems.
